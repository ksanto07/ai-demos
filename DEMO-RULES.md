# Demo recording rules

0. Preflight env, keys, and a dry run off camera. Stop and ask if a key is missing.
1. Already set up on camera. Install, keys, and config stay off camera.
2. Open with a one-line caption that states the problem.
3. One real live run. Nothing faked.
4. One command to the result.
5. Captions. No narration in the take. Kenneth adds the voiceover.
6. 60 to 90 seconds.
7. Phone-readable and croppable. Nothing important sits at the edges.
8. Kenneth voiceover.
9. Close with a caption that lists what it does not do yet.
